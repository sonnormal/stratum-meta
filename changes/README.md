# 📑 Stratum Change Archive

This directory maintains the immutable, historical records of all **Change Requests (CRs)** in the Stratum ecosystem.

Every change request moves through the 3 Human Governance Gates documented in [`../docs/workflow.md`](../docs/workflow.md):
1. **`GATE-01`**: Value & Feasibility (Scope, Cybersecurity, Cost-Benefit)
2. **`GATE-02`**: Contract & Test Scenarios (Plain-language edge cases before code synthesis)
3. **`GATE-03`**: User Acceptance Sign-off (Live verification in container environment)
